# Instructivo de Producto — Converse, Fila y Umbro

Instructivo de producto interactivo para las marcas **Converse**, **Fila** y **Umbro**.

## Archivo

- [`Instructivo_Converse_Fila_Umbro.html`](Instructivo_Converse_Fila_Umbro.html) — documento único y autocontenido (HTML + CSS + JS + imágenes embebidas). No requiere servidor ni dependencias: se abre directamente en cualquier navegador.

## Contenido

- Navegación estilo converse.cl con mega menú por marca.
- Secciones por marca: **CORE**, **CARRY OVER**, **NEW**, **OLD**, **GUÍA DE SUPERFICIES** e **HISTORIA**.
- Buscador por código de modelo con filtros y resaltado de coincidencias.
- Fichas desplegables por modelo con selector de color.

## Uso

Abrir `Instructivo_Converse_Fila_Umbro.html` en el navegador (doble clic o arrastrar a una ventana). Funciona en escritorio y móvil.

## Edición

Todo el contenido vive en el mismo archivo HTML. Al editarlo, mantener la estructura y los estilos existentes para conservar el formato.
